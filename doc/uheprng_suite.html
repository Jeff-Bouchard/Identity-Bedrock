Benchmark / run instructions

Use the bash launcher to run the benchmark, pick a free port above 50000, and serve the suite locally.

bash run_uheprng_suite.sh all # just the benchmark bash run_uheprng_suite.sh bench --seed ness-demo-123 --iters 250000 # serve without auto-benchmarking bash run_uheprng_suite.sh serve --port 50077

Why this suite matters

The point is not just random numbers. The point is replayable stochastic behavior: same seed, same state, same output, same audit trail. That is what makes the demos useful for verifiable AI, fairness, and state recovery.

- deterministic replay - bounded entropy control - seed-anchored output verification - resumable state snapshots - local-only / offline-friendly execution
The benchmark is intentionally lightweight and can be run on the same machine that serves the demos. If you need a more formal benchmark, I can extend this into per-test latency percentiles, memory usage, and multi-seed stability runs.
