\begin{abstract}
We present Identity Bedrock, a deployed identity system constructed from a minimal cryptographic substrate. Starting from the requirement that no institutional key exists beneath the individual, we derive an architecture grounded in one-way functions (OWFs).

The system separates identity cryptography from directory consensus via a chain-agnostic, append-only binding layer.

The system has been deployed in production for over five years, with publicly verifiable records and continuous operation.

We show that naming, structured representation, content retrieval, execution, connectivity, and economic interaction emerge as derived properties of this identity substrate.
\end{abstract}
